# SOC Engineering Home Lab

## Project Overview

This repository documents my hands-on journey building, configuring, and maintaining a Security Operations Center (SOC) home lab.

The purpose of this project is to develop practical experience in security information and event management (SIEM), endpoint monitoring, threat detection, security automation, and incident investigation.

## Project Objectives

- Deploy and administer Windows and Linux virtual machines.
- Install and configure Splunk Enterprise.
- Collect and analyze Windows Security and Sysmon logs.
- Develop custom SPL detection searches.
- Map security detections to the MITRE ATT&CK framework.
- Practice threat hunting and incident investigation.
- Automate security monitoring tasks using Python and PowerShell.
- Document troubleshooting, architecture, and lessons learned.
